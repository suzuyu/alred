# alred Manuals

alredの利用者向けマニュアルを、利用目的ごとに案内する入口です。

## 現在利用できるマニュアル

| 分野 | 対象 | 入口 |
|---|---|---|
| Network operations | NX-OSの正常性確認、EVPN/VXLAN変更、設定投入を行う運用者 | [Network Operations Manual](./network-ops/README.md) |

現在整備済みの利用者向けマニュアルはnetwork operationsです。containerlabによる構築や
構成図作成など、他分野の階層とマニュアルは別タスクで現行実装を確認したうえで追加します。

## 文書の位置付け

利用手順は各分野のマニュアルを参照してください。機能仕様の正本は
[設計書一覧](../design/README.md)、実装状況は
[Implementation Status](../implementation/IMPLEMENTATION_STATUS.md)です。
