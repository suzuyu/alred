共通データ形式・schema のレビュー

nexthop-include = prefix + AD + next-hop。interface と参照先 VRF を含み、AD と next-hop の対応も比較します。

採用方式: Prefix + AD + Cost / Prefix + AD + Cost + NextHop
Cost は [110/20] の 20（metric）です。AD と Cost、NextHop の対応を保持します。既定表示と主差分は Cost 込みとします。
