# alred 0.2.0a1

`0.2.0a1`は、NX-OS EVPN/VXLAN環境の作業前後の正常性確認と、Overlay変更のplan・承認・投入・保存・切り戻しを、共通のoperation成果物で追跡できるようにしたalpha releaseです。従来のcollect、topology、containerlab、VNI map/config、config push系CLIは維持します。

## 主な変更

- `health-check before/after/rollback`を追加し、直接収集または外部logからのSnapshot生成、機器別checklist、作業前後比較に対応しました。
- NX-OSのCPU、memory、environment、reload-pending、logging、OSPF、BGP、route、vPC、EVPN/VXLAN Overlay状態をprofileに基づいて判定できるようにしました。
- `overlay-check discover/evaluate/converge`を追加し、新規L2VNI/L3VNIと関連するVLAN、VRF、SVI、NVEの自動発見と収束判定に対応しました。
- `overlay-change prepare-plan/plan/approve/apply/save/rollback/save-rollback`によるmanaged Overlay change workflowを追加しました。
- 外部ファイルと階層化に対応したdevice group、ChangeSet schema、NX-OS forward/rollback configの共通rendererを追加しました。
- VLAN、VNI、VRF、SVI IPの競合検査と、投入前のrunning configとplanの比較を追加しました。安全に判定できない場合はfail closedで停止します。
- operation単位の承認、排他制御、attempt履歴、生log、config、hash、判定根拠を保存できるようにしました。
- rollback後に、before running configとのraw差分とOverlay semantic configの一致を検証できるようにしました。
- redaction、checksum、Manifest、AI向けpromptを含む`support-bundle create/inspect/verify`を追加しました。

## 初期対応範囲

- NX-OSの初期対象は`10.4(5)M`以降です。applyの許可は、Capability Registryのexact `model + release + role + capability set`一致で判定します。
- `N9K-C9300V` / NX-OS `10.5(4)` / `vpc_vtep_leaf`は、Nexus 9000v labでqualificationと通常のapply/save/rollback/save-rollbackを受入済みです。
- Nexus 9336C-FX2、93180YC-FX3、9348GC-FX3、9364C-H1は10.4(5)Mの公式資料とmodel別golden configで静的確認済みです。実機動作は検証せず、`APPLY_VERIFIED`として扱いません。

## 互換性と移行

- 従来CLIに意図的な破壊的変更はありません。新機能を利用しない既存workflowに移行操作は必要ありません。
- managed workflowは、`operations/`配下のchange ID別workspaceに新しいschemaと成果物を作成します。実行前に[Network Operations Manual](../manual/network-ops/README.md)と設計上の制約を確認してください。

## 既知の制約

- 本バージョンはalphaです。alredによる動作検証対象はNexus 9000vだけです。
- Nexus 9336C-FX2、93180YC-FX3、9348GC-FX3、9364C-H1は実機検証対象外です。公式資料と機種別golden configによる静的確認だけを行い、実機での投入、保存、収束、rollbackを保証しません。
- Nexus 9000v上のNX-OS 10.4(5)M、未登録release、実配布先OSでのbinary起動は未検証です。
- 標準ReleaseはLinux x86_64 glibc 2.17のみです。glibc 2.28/2.34、Linux aarch64、Windowsは配布対象に含めません。
- 自動テストでは`device` markerを除外しています。実機操作は、明示的に指定された対象と許可の下で別途実施します。
