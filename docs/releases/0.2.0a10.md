# alred 0.2.0a10

`0.2.0a10` は、Portable Evidence Package を省略時の既定 source として安全に再利用できるようにし、
Topology の node／interface 除外と role 定義済み node の確認用 draw.io page を追加する alpha release です。

## 主な変更

### Evidence Package の自動選択と互換再検証

- `alred evidence-package import` で `--bundle` を省略した場合、`evidence-packages/` 内の archive と
  checksum を検証し、Package の `created_at` が最新の組を選択します。
- 自動選択時に欠損、unsafe、破損、checksum 不一致などの archive 候補がある場合は、正常な Package を
  暗黙に選ばず `EVIDENCE_INVALID_SOURCE` で fail closed します。
- Secret Scan Rule Catalog の schema version が同じで catalog hash だけが異なる旧 Package は、現在の
  catalog で再 scan してから import します。未知の catalog version、secret 検出、Package integrity 不一致は
  引き続き拒否します。
- Evidence Package 系 error の CLI 表示で、同じ error code が二重に表示される問題を修正しました。

### 最新 import を使用する既定 source

- source option をすべて省略した `normalize-links`、`generate-mermaid`、`generate-network-diagram`、
  `clab-transform-config`、`clab-set-cmds` は、検証済み Package を指す `imported-evidence/latest` を
  既定 source として使用します。
- `--input`、`--hosts`、`--mappings` などの local source、明示した Evidence Package、external import、
  Operation source は従来どおり優先します。
- offline Evidence Package を既定 source にした `clab-set-cmds` は device access や config 投入を行いません。

### Topology の除外規則と Defined Roles page

- `mappings.yaml` に、大文字・小文字を区別しない部分一致の `exclude_node_name_contains` を追加しました。
  一致 node を endpoint に持つ LLDP／description link は confirmed／candidate と diagram から除外します。
- 同梱 `description_rules.example.yaml` は `MGMT`、`mgmt`、`vPC-peer-link`、`vpc-peer-link` を
  interface token として認識し、これらの文字列だけの description を hostname として扱いません。
- `topology-graph-all.drawio` に `Topology Defined Roles TD` page を追加しました。明示 `group` または
  `roles.yaml` で定義された role の node だけを描画し、未定義 role と `default`／`other` を除外します。
  定義済み node は link がなくなっても standalone node として残します。
- `--all-graph` の既定 page 数は 10、全 4 方向は 18、`--no-overlay-service` ではそれぞれ 8／14 です。

## 互換性と移行

- `--bundle`、`--evidence-package`、`--input` などを明示する既存 command は維持します。
- 既存 `mappings.yaml` は変更せず使用でき、`exclude_node_name_contains` を省略した場合は node 名で除外しません。
- NetworkDiagramManifest v1 に `defined_roles_only_page` を optional field として追加しました。旧 Manifest は
  引き続き受理し、省略時は `false` と解釈します。
- `--all-graph` の draw.io は Defined Roles page の追加により page 数と page 順が変わります。
  page 名を使用する自動処理は `Topology Defined Roles <direction>` を考慮してください。
- Secret Scan Rule Catalog の hash が異なる旧 Package は現在の catalog で再評価されるため、現在の rule で
  secret が見つかった場合は以前 import できた Package でも拒否されます。

## 既知の制約

- 本 version は alpha です。未登録 model、release、role、Capability の設定投入は許可しません。
- `evidence-package import` の自動選択は、`evidence-packages/` 内に invalid archive 候補が 1 件でもある場合は
  fail closed します。対象を限定する場合は `--bundle` と必要に応じて `--checksum-file` を明示してください。
- 省略時の Evidence consumer source を使用するには、先に `evidence-package import` を成功させ、
  `imported-evidence/latest` を公開しておく必要があります。
- Defined Roles page は `--directions` の先頭方向を使用します。明示 `group` は `roles.yaml` の
  `role_detection` key と一致する必要があります。
- 標準 Release は Linux x86_64 glibc 2.17 binary だけです。glibc 2.28／2.34、Linux aarch64、
  Windows binary は含めません。
- 自動 test では `device` marker を除外しています。実機への接続や設定投入は実施していません。
