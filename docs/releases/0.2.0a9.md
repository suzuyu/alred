# alred 0.2.0a9

`0.2.0a9` は、物理 link の不整合を構成図と report で追跡できるようにし、
外部 NX-OS transcript に複数の取得世代が含まれる場合の安全な選択を追加する alpha release です。

## 主な変更

### Link 不整合の診断と構成図表示

- LLDP と interface description の対向 device／interface 不一致、双方向 description の
  非相互 claim、双方向 LLDP evidence がある場合の片方向 LLDP、複数 peer、
  曖昧な description を診断します。
- machine-readable な`link-diagnostics.yaml`と、利用者向けの`mismatch-links.md`を生成します。
  Summary に mismatch の対象 device 一覧を含めます。
- Physical／Underlay 構成図で conflict を赤色、warning を amber の link とし、
  link 上に診断 code を表示します。Confirmed Links page には、その page で
  非表示の診断件数と`mismatch-links.md`への案内を表示します。
- inventory 外の peer、対象 device の running-config／LLDP 未取得、または比較可能な
  対向 evidence がない片方向 claim は mismatch と断定ず、`unevaluated_claims`として
  `link-diagnostics.yaml`に保存します。`mismatch-links.md`では詳細を error として列挙しません。
- Portable Evidence Package は LinkDiagnostics を optional canonical resource として保持できます。

### NX-OS transcript の重複世代選択

- `--transcript-duplicate-policy safe-latest`を既定値とし、同一出力の自動 dedup と
  同一 file 内の後方区間選択を追加します。
- 異なる file 間の出力が異なる場合は既定で fail closed とし、
  `--transcript-file-order mtime`または`--transcript-file-order filename`を明示した場合だけ
  最新候補を選択します。
- `filename`では`after > work > before`の順に優先し、同じ phase の候補は
  `YYYYMMDDTHHMMSS`、`YYYYMMDD_HHMMSS`、`YYYYMMDD-HHMMSS`を比較します。
- `COLLECTED_AT:`は必須条件や主な選択根拠としません。選択候補、出力 hash、
  行範囲、選択理由は`transcript-import-manifest.yaml`の`duplicate_groups`に記録します。

## 互換性と移行

- 既存の confirmed／candidate CSV header と diagram 生成 command は維持します。
- LinkDiagnostics、NetworkDiagramManifest、EvidencePackageManifest、TranscriptImportManifest、
  HealthCheckExecutionContext の schema 変更は additive とし、旧 artifact を受理します。
- transcript の重複は既定で`safe-latest`に変わります。従来どおりすべての重複を
  曖昧として扱う場合は`--transcript-duplicate-policy reject`を指定してください。
- `normalize-links`と`generate-network-diagram`は診断用 artifact を追加生成しますが、
  既存の canonical CSV 出力は維持します。

## 既知の制約

- 本 version は alpha です。未登録 model、release、role、Capability の設定投入は許可しません。
- `filename`の phase 優先は`--phase`に応じた filter ではありません。before Snapshot には
  `after`を含まない before 専用 directory を指定してください。
- alred が取得した`health/<phase>/raw/`の再解析は、prompt のない running-config／LLDP artifact も
  取り込むため`--input-format alred-collect`を推奨します。
- 未評価 claim の詳細は`link-diagnostics.yaml`で確認してください。
- 標準 Release は Linux x86_64 glibc 2.17 binary だけです。glibc 2.28／2.34、Linux aarch64、
  Windows binary は含めません。
- 自動 test では`device` marker を除外しています。実機への接続や設定投入は実施していません。
