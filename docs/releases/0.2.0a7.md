# alred 0.2.0a7

`0.2.0a7` は、site metadata の解決と topology draw.io の確認性を改善する alpha release です。
Evidence Package の inventory で site が未指定の場合も、固定済み `sites.resolved.yaml` の hostname rule を使用して
Physical／EVPN／Overlay Service diagram の site を一貫して解決します。

## 主な変更

### Site 解決

- inventory の site が YAML `null` の場合に文字列 `"None"` として扱われ、site detection rule への fallback が
  停止する問題を修正しました。
- Physical、EVPN、Overlay Service の各 diagram で同じ site 解決結果を使用します。
- `site_detection.priority` が未指定、または site が未定義の場合の既定値を `99` から `1000` へ変更しました。
  topology renderer と Health Check の `device-summary.md`／CSV に同じ既定値を適用します。
- role priority の既定値 `99` は変更していません。

### draw.io

- `--all-graph` の multi-page draw.io に `Topology Confirmed Links TD` page を追加しました。
- この page は `links_confirmed.csv` の link と endpoint node だけを描画し、candidate link を含めません。
- 既定 page 順は `Topology TD`、`Topology Confirmed Links TD`、`Topology LR`、Underlay、EVPN、
  Overlay Service の順です。
- 既定 page 数は 9、`--directions TD,LR,BT,RL` では 17、`--no-overlay-service` では 7／13 です。

## 互換性と移行

- CLI option、既存 artifact file 名、既存 8 page の名称は変更していません。
- `topology-graph-all.drawio` の page 数と順序は変わります。page index に依存する consumer は、page 名での参照へ
  移行してください。
- site priority を省略していた環境では、明示 priority `100` などが未指定 site より先に並ぶようになります。
  固定順が必要な site には `priority` を明示してください。

## 既知の制約

- 本 version は alpha です。未登録 model、release、role、Capability の設定投入は許可しません。
- EVPN／Overlay Service diagram は、必要な operational evidence が不足または競合する場合に `PARTIAL` となります。
- `Topology Confirmed Links TD` は link confidence を再判定せず、同じ実行で正規化・固定した
  `links_confirmed.csv` を描画します。
- 標準 Release は Linux x86_64 glibc 2.17 binary だけです。glibc 2.28／2.34、Linux aarch64、
  Windows binary は含めません。
- 自動 test では `device` marker を除外しています。実機への接続や設定投入は実施していません。
