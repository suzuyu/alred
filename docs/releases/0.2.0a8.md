# alred 0.2.0a8

`0.2.0a8` は、長期間運用する operation と Portable Evidence Package の保守性を改善する alpha release です。
stale operation の明示終了・復元、Evidence の安全な世代整理、Health Check checklist の異常項目集約を追加します。

## 主な変更

### Operation lifecycle と archive

- Health Check の change 用 before は `waiting_for_user` とし、後続の Overlay plan で処理を再開します。
- inspection、単独 after／rollback、Overlay save の成功時に operation を terminal state へ遷移させます。
- 長期間放置された operation を operator 判断で終了する `operation close` を追加しました。
- operation status に stale 表示を追加し、archive 済み operation を検証して live state に戻す
  `operation restore` を追加しました。
- operator close による canceled operation の `--older-than-days` は、close 時刻ではなく close 前の最終活動時刻を
  基準に判定します。

### Portable Evidence Package

- `evidence-package create` の自動 source 選択時に、実体 directory が存在しない operation index entry を
  自動削除します。
- 作成済み archive／checksum pair を profile・通常／sensitive 区分ごとに最新 3 世代保持します。
  `--keep-latest-packages`、`ALRED_EVIDENCE_PACKAGE_KEEP_LATEST`、`evidence-package prune --dry-run` を
  使用できます。
- `imported-evidence/` も import 日時を基準に同区分ごとの最新 3 世代を保持します。
  `ALRED_EVIDENCE_IMPORT_KEEP_LATEST` と `evidence-package prune-imports --dry-run` を追加しました。
- archive、checksum、Manifest、import record、member hash を検証できない成果物と、`latest` の参照先は
  自動削除しません。保持数 `0` で自動整理を無効にできます。

### Health Check checklist

- `checklist.md` の `Result by Profile` に、`WARN`、`FAIL`、`UNKNOWN` となった check と該当 hostname を
  profile ごとに表示します。

## 互換性と移行

- 既存 operation、Evidence Package archive、import directory の schema と明示 path は維持します。
- Evidence の自動保持は既定で 3 世代です。従来どおり全世代を残す場合は、対応する環境変数または
  `--keep-latest-packages 0` を指定してください。
- 自動削除は完全に検証できた管理対象だけに限定されます。不明な file や directory は `SKIP` として残ります。

## 既知の制約

- 本 version は alpha です。未登録 model、release、role、Capability の設定投入は許可しません。
- operation の自動 archive は行いません。stale state の確認、明示 close、archive の順に operator が判断します。
- Evidence retention で検証不能として `SKIP` された成果物は、内容確認後に手動で整理する必要があります。
- 標準 Release は Linux x86_64 glibc 2.17 binary だけです。glibc 2.28／2.34、Linux aarch64、
  Windows binary は含めません。
- 自動 test では `device` marker を除外しています。実機への接続や設定投入は実施していません。
